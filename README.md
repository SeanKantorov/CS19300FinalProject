# CS19300FinalProject
This is my own personal workout tracker.
For the MVP the product must be able to run everyday, track what workout if any has occured, and then record the data. The data should be recorded twice, once in a human readable format, and another in machine readable in order to handle future data processing I want to run to see my progress over time.
In the future I would like to add visual data processing to see things like if I have gotten stronger, how consistent I am and other metrics like that. It would also be nice to see it in a visual format rather than just a terminal application.

The project should use:
* bash
    * cron
* java
    * IO
* python (future plans)
    * matplotlib
